# Security Policy · Política de Segurança

## Current status

Igor Cloud is an early-stage project. It does not currently provide a production file-storage service. Security principles documented in this repository are design intentions, not a claim that application controls have already been implemented.

## Reporting a vulnerability

Please do not publish credentials, private files, access tokens or exploitable vulnerability details in a public issue.

Use GitHub's private vulnerability reporting feature for this repository if it is enabled. If private reporting is unavailable, contact the repository owner through the contact information on the GitHub profile and share only the minimum information needed to establish a safe communication channel.

## Scope

Reports are most useful when they identify a concrete security risk in code or configuration that exists in this repository. The current repository is primarily documentation, so reports about unimplemented features should be framed as design concerns rather than confirmed vulnerabilities.

## Responsible disclosure

Please allow reasonable time for investigation and remediation before publicly disclosing a confirmed vulnerability. Do not access, modify or delete data that does not belong to you while testing.
